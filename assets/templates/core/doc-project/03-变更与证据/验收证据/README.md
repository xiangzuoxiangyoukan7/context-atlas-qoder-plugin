# 验收证据

从 `.project-kb/templates/knowledge/acceptance-evidence.md` 创建报告。证据应记录命令、环境、时间、输出摘要、失败项和对应版本；大文件可保存外部引用，但必须可追溯。

不得伪造第二个 Agent、人工确认或未运行的测试。无法取得的证据将结果保持为 `partial` 或 `not_started`。
