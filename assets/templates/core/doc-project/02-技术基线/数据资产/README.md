# 数据资产

## 目录契约

本目录只保存跨技术对象的数据资产治理知识，不重复数据库字段或接口结构。数据资产使用稳定身份命名，并以 `rel_classified_under` 指向本 README。使用 `children` 查看目录内容、`neighbors` 查询直接成员；普通 `graph` 到达本 README 后停止，只有显式分类成员查询才继续展开。

数据资产卡记录数据的业务含义、质量要求、安全要求和保存规则。每张卡使用 `DATA-<three digits>` 编号，并链接相关技术契约；不复制数据库字段、接口载荷或实现细节。
