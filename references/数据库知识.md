# 数据库知识

## 什么时候读取

当用户要求记录数据库、多数据源、多模式、表字段、值域、数据库变化或主子表关系时读取本文，并继续遵守正式写入 Proposal 和显式确认流程。

## 产品层级

| 产品 | 数据源 | 数据库单元 | 可选命名空间 |
| --- | --- | --- | --- |
| Oracle | 实例或集群 | PDB；CDB 作为可选拓扑 | Schema/用户 |
| PostgreSQL | 服务器或集群 | Database | Schema |
| KingbaseES | 服务器或集群 | 数据库 | 模式 |
| MySQL | 实例或集群 | Database/Schema | 不重复建立 |

如果真实产品没有独立命名空间，不创建空目录实体。层级关系统一使用 `rel_belongs_to`。配置只保存位置或环境变量名，绝不保存凭据值。

## 表和字段

业务表默认一表一文件。每个字段必须填写中文含义、可空、默认值、值域、是否允许其他值、约束执行位置和具体来源链接。值域使用中文类型：枚举、范围、格式、任意、未知；未知必须说明缺口，不能伪造值域。

已有物理外键必须如实记录真实约束名，但 Context Atlas 不要求新增物理外键。无论是否存在物理外键，逻辑外键都必须在子表保存 `rel_logical_parent`，并用 `[[主表文件#^FIELD-ID|FIELD-ID]]` 精确链接主字段。

数据库作为基础知识，被功能、接口、需求和任务通过 `rel_reads`、`rel_writes`、`rel_depends_on` 引用。数据库文件不得反向手填业务消费者；使用反向索引和影响分析读取。
